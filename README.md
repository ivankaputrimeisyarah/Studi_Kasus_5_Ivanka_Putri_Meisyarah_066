1. Pertama membuat function dan memasukkan parameter yang telah ditentukan yaitu jenis kendaraan dan durasi.
2. Selanjutnya menggunakan "if" untuk mengecek jenis kendaraan. Jika jenis kendaraan adalah mobil maka tarif yang dikenakan adalah Rp5.000 per jam.
3. Kemudian saya menggunakan "elif" untuk mengecek jenis kendaraan lainnya yaitu motor. Jika kendaraan adalah motor maka tarif yang dikenakan adalah Rp3.000 per jam.
4. Selanjutnya sistem akan menghitung total biaya parkir dengan rumus (tarif * durasi).
5. Setelah mendapatkan hasil perhitungan saya menggunakan return untuk mengembalikan hasil total biaya parkir dari function.
6. Selanjutnya menggunakan input() agar user dapat memasukkan data berupa jenis kendaraan, jam masuk, dan jam keluar.
7. Kemudian sistem menghitung durasi parkir dengan rumus (jam_keluar - jam_masuk).
8. Memanggil function dengan memasukkan data jenis kendaraan dan durasi sebagai argumen.
9. Terakhir menggunakan print() untuk menampilkan output seperti jenis kendaraan, jam masuk, jam keluar, lama parkir, dan total biaya parkir.
